# AVIF con libavif/AOM

Fecha: 2026-10-31 · Tarea: `t-44`

## Decisión

Se retira ravif del camino de salida y se integra `libavif-sys` con AOM 3.11
estático. Las variantes de ravif (8/10 bits, YCbCr/RGB, speed 2–8) no cerraban
la brecha de UI; AOM sí.

Configuración:

- RGBA8 → YUV420, BT.601, rango completo.
- `end-usage=q`, `cq-level`, `sharpness=0`, `denoise=0`.
- `tune=ssim` cuando el cuantizador es ≤ 32.
- Calidad HUNK 1–100 mapeada al cuantizador 0–63 de libavif.
- Alpha quality propia; 0 significa “misma que color”.
- `maxThreads` según CPUs disponibles.

## Build

- AOM se compila con CMake y NASM y se enlaza estáticamente.
- No añade DLLs de runtime.
- Linux: binario de 26,1 MB (+4,2 MB).
- Windows GNU: build cruzada validada localmente; 23,8 MB.
- La build MSVC de Windows queda para el CI.
